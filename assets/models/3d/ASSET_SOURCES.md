## Download Instructions for Sketchfab Assets

1. Open the Sketchfab link in your browser
2. Click the **Download** button (bottom left)
3. Choose **glTF** or **Geometry only (GLTF)** format
4. Save to the corresponding folder in `assets/models/3d/[category]/`
5. Rename if needed to match the guide above

## Attribution Format

For each CC-BY asset downloaded, add entry to `ATTRIBUTION.md`:
```
- [Model Name] by [Creator]
  - Source: Sketchfab / Poly Haven
  - License: CC-BY / CC0
  - Link: [original link]
  - Downloaded: [date]
```

## Notes

- **GLTF vs FBX vs OBJ**: Choose GLTF when available - it's the native Godot format
- **File size**: Low-poly models (marked "low poly") are better for performance
- **Textures**: Some models have embedded textures in GLTF format, others may need separate texture files
- **Import Settings**: Godot will auto-import GLB files as mesh resources
- **Next Step**: After downloading all GLB files, we'll create .tscn scene wrappers for each model
